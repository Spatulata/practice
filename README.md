# Основы Python

Учебное приложение (Python 3, Tkinter).

## Автор

- Поляков Сергей Русланович, ВО-ТМ-21

## Запуск

```
python main.py
```

Нужен Python 3.8+ с tkinter. Внешние библиотеки не нужны.

## Файлы

- `main.py` — интерфейс
- `practice.py` — задания и отчёт
- `topics_data.py` — темы и тест
- `example_report.txt` — пример отчёта

## Темы

1. Типы данных
2. Списки и кортежи
3. Словари
4. Условия и циклы
5. Списковые включения
6. Исключения
7. `*args` и `**kwargs`
8. Итоговый тест

Результат теста сохраняется в `result_report.txt`.
